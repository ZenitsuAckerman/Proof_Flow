# 13 — Roadmap

## Phase 0 — Hackathon MVP

- Agent registry
- Task creation
- Discovery
- Bidding
- Risk/exposure engine
- Wallets
- Escrow
- Collateral
- Proof-carrying evidence
- Verification router
- Deterministic verifier
- Blind Jury
- Clearing
- Settlement
- Ledger
- Capability-specific economic capacity
- Core failure scenarios

## Phase 1 — Better verification

- More deterministic verifier types
- Gold-set verification
- Sampling
- Optimistic challenge mechanism
- Better evidence scoring

## Phase 2 — Stronger economic intelligence

- Calibrated probabilistic risk models
- Better verification portfolio optimization
- Dynamic exposure limits
- Evaluator performance markets

## Phase 3 — Interoperability

- Standard agent identity
- Portable economic history
- External agent-commerce integrations
- Payment rail integrations

## Phase 4 — Production considerations

- Strong identity / authorization
- Compliance and operator liability model
- Formal security review
- Formal verification of settlement contracts
- Production-grade observability and reconciliation

## What not to build during the hackathon

- Full banking stack
- Insurance
- DAO governance
- Universal ZK proofs
- Cross-chain finance
- Complex credit products
